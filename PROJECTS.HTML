Library Management System

Project Overview

The Library Management System is a console-based C program designed to help manage books in a library. It performs essential operations such as adding, viewing, searching, modifying, deleting, issuing, and returning books, and stores all data permanently in binary files. This project demonstrates file handling, structures, user input validation, and menu-driven programming in C.

🎯 Objectives

  • 📚 To automate library record management
  • 🔄 To efficiently track books, issues, and returns
  • 💻 To demonstrate practical use of file I/O and data structures in C
  • 🎯 To provide a learning-level example of a real-world management system

⚙️ Technical Details

  • 💻 Language Used: C Programming
  • ⚙️ Compiler: GCC (GNU Compiler Collection)
  • 🖥️ Type: Console Application
  • 💾 Data Storage: Binary files (books.dat, issues.dat)
  • 🏗️ Structures Used: Book, Issue
  • 📚 Programming Concepts Used: File handling, Structures, Loops, Conditional statements, Functions, Switch-case menu

🧩 Data Structures

Data Structures

📚 Book Structure 
typedef struct {
    int id;
    char title[100];
    char author[100];
    char publisher[100];
    int quantity;
} Book;
  • id → Unique identifier
  • title, author, publisher → Text info
  • quantity → Number of available copies
📖 Issue Structure 
typedef struct {
    int book_id;
    char student_name[100];
    char issue_date[20];
} Issue;
  • Which book ID was issued
  • To which student
  • On what date

🧠 Core Functionalities

System Functions
  • ➕ Add Book — Add a new book record to books.dat
  • 📚 Display All Books — View all stored books in a table format
  • 🔍 Search by ID — Search a specific book using its ID
  • 🔎 Search by Title — Search books by name or partial text
  • ✏️ Modify Book — Edit book details (title, author, publisher, quantity)
  • 🗑️ Delete Book — Remove a book permanently from the file
  • 📤 Issue Book — Issue a book to a student and reduce its quantity
  • 📥 Return Book — Return a book, increase quantity, remove issue record
  • 🚪 Exit — Quit the system safely

💾 Files Used

  • 📁 books.dat — Stores all book details (binary format)
  • 📄 issues.dat — Stores records of issued books
These files ensure data persistence — meaning data remains saved even after the program is closed.

🧮 Important Utility Functions

Helper Functions

Function Description
clear_stdin() Clears leftover input to avoid invalid reads
pause_and_clear() Pauses program for user to read output
removeNewline() Removes newline from fgets() input
bookExists() Checks if a book exists by ID
updateBookRecord() Updates a specific book record in the file

🧪 Sample Workflow

  • ➕ Add a book → e.g. ID = 101, Title = "C Programming"
  • 📚 Display all books → confirm it’s added
  • 📤 Issue the book → enter student name & date
  • 📥 Return the book → restores quantity
  • 🚪 Exit program → data remains stored in .dat files

💡 Advantages

  • 📁 Demonstrates real-world file-based record management
  • 💻 Works on any OS (Windows, Linux, Mac)
  • 🗄️ No database needed — uses .dat files for storage
