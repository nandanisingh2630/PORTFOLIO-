# Personal Portfolio Website

This is a personal portfolio website created using **HTML, CSS, and JavaScript** to showcase profile information, skills, experience, and projects. The website has a clean layout and simple navigation between different sections.

## Features
- About section with personal introduction  
- Skills section  
- Experience section  
- Projects showcase  
- Profile picture display  
- Responsive and simple design  
- Basic JavaScript for interactivity  

## Project Structure

portfolio/

│── experience.html
│── project.html
│── style.css
│── script.js
│── profile.jpg
│── README.md


## Pages Description
- **index.html** – Home page of the portfolio  
- **about.html** – Contains personal information  
- **skills.html** – Displays technical skills  
- **experience.html** – Shows experience details  
- **project.html** – Lists projects  
- **style.css** – Website styling  
- **script.js** – JavaScript functionality  
- **profile.jpg** – Profile picture  

## Technologies Used
- HTML  
- CSS  
- JavaScript  

## Purpose
This portfolio website is created to present personal details, skills, and projects in a structured and professional way.
